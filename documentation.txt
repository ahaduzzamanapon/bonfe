3 API Create (Occupation/Tread Course, Institute/Training Center, Learner Data)



API Documentation
================

This document provides documentation for the Bonfe API.

--------------------------------------------------

### 1. Get Occupations

**Description:**
Returns a list of all occupations.

**URL:** `{{base_url}}/api/v1/get_occupations`
**Method:** `GET`
**Headers:**
- `x-api-key`: Your API Key

**Example Response:**
```json
{
    "success": true,
    "data": [
        {
            "id": 3,
            "name": "General"
        },
        {
            "id": 4,
            "name": "Computer Operation and Graphics Design"
        }
    ]
}
```

### 4. Get Learner

**Description:**
Returns a list of learners. Supports pagination and fetching all learners at once. All learners are filtered to be on or after 2025-12-14.

**URL:** `{{base_url}}/api/v1/get_learner`
**Method:** `GET`
**Headers:**
- `x-api-key`: Your API Key

**Query Parameters:**
- `page` (optional): The page number for pagination.
- `per_page` (optional): The number of items per page for pagination.
- `all` (optional): Set to `true` to get all learners at once.

**Example URL for pagination:** `{{base_url}}/api/v1/get_learner?page=1&per_page=10`
**Example URL to get all:** `{{base_url}}/api/v1/get_learner?all=true`

**Example Response (Paginated):**
```json
{
    "success": true,
    "data": {
        "current_page": 1,
        "data": [],
        "first_page_url": "http://bnfe.mysoftheaven.com/api/v1/get_learner?page=1",
        "from": null,
        "last_page": 1,
        "last_page_url": "http://bnfe.mysoftheaven.com/api/v1/get_learner?page=1",
        "links": [],
        "next_page_url": null,
        "path": "http://bnfe.mysoftheaven.com/api/v1/get_learner",
        "per_page": 10,
        "prev_page_url": null,
        "to": null,
        "total": 0
    }
}
```
